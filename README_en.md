# Granting access to an app running in a Yandex Managed Service for Kubernetes® cluster

To grant access to an app running in a [Managed Service for Kubernetes®](https://yandex.cloud/docs/managed-kubernetes) cluster, you can use various types of public and internal services. See this [tutorial](https://yandex.cloud/docs/managed-kubernetes/operations/create-load-balancer) to learn how to prepare the infrastructure for Managed Service for Kubernetes® using Terraform. This repository contains the configuration file you will need: [k8s-load-balancer.tf](k8s-load-balancer.tf).
